# QQ ComfyUI Tools

为 ComfyUI 提供媒体、视频、H3、Qwen 和 Lightroom 工具节点。

## 安装

将仓库放入 ComfyUI 的 `custom_nodes/QQ_ComfyUI_Tools`，重启 ComfyUI。`QQ-视频补帧×2` 另需安装 WhiteRabbit/RIFE 节点并准备 `rife47.pth`；其他节点使用 ComfyUI 已有的依赖。

## 节点

| 分类 | 节点 | 用途 |
| --- | --- | --- |
| `QQ/视频` | `QQ-视频开头黑屏` · `QQ-视频补帧×2` | 替换视频开头、分块补帧 |
| `QQ/H3` | `QQ-H3分段时长` · `QQ-H3提示词` · `QQ-H3功能区路由` · `QQ-H3 分段彩噪` | 分段参数、提示词和二采预处理 |
| `QQ/工具` | `QQ-保存视频` · `QQ-多媒体加载` · `QQ-媒体序号输出` · `QQ-自动拆分媒体` | 保存、选取与拆分媒体 |
| `QQ/工具` | `QQ-多值设置` · `QQ-多值输入` · `QQ-长宽交换` · `QQ-潜空间切换` · `QQ-绕过规则` · `QQ-获取点` · `QQ-魔术贴` | 工作流控制 |
- `QQ-多值输入` 连到名字精确为 `模式` / `启用` / `规则` 的输入口时，节点体内控件标签会继承**该输出口的自定义名**（右键重命名输出口即可），与右侧输出口行显示一致；没改过名或改名被清掉时显示目标输入口名。只读取本节点输出口的自定义名，不读取、不拼接连接节点的任何信息，也不修改其它节点。多值输入发出的连线平时 **100% 透明**（完全隐形），改为在「有连线的输出口」上画一个草绿色呼吸光晕（1px 线宽、半径 2→3px 微微扩散）提示这里有虚拟连接；选中或悬停连线任一端节点时连线以 90% 亮草绿 + 流动高亮出现。只改连线/绘制属性，不改拓扑。
| `QQ/工具` | `QQ-图像轮询切换` · `QQ-文本轮询切换` · `QQ-多行文本` · `QQ-文本合并` | 图像和文本处理 |
| `QQ/Qwen` | `QQ-Qwen Image 2.1 AI提示词增强(PE or API)` | 官方 PE 或 API 提示词增强 |
| `QQ/图像生成` | `QQ-Grok图像生成` · `QQ-Qwen Image 2.1 一键出图(编码+K采样+VAE解码)` | 图像生成 |
| `QQ/LR 调色` | `QQ-LR-光线调节` · `QQ-LR-色彩调节` · `QQ-LR-基础增强` · `QQ-LR-暖色调色` · `QQ-LR-冷色调色` · `QQ-LR-颗粒效果` | 可串联的图像调色 |

## 常用接线

### 多媒体

`QQ-多媒体加载` 可浏览 ComfyUI 的 input/output 目录、搜索和排序文件，也支持拖入媒体。`external_images` 可接外部图片；在节点内指定插入序号后，外部图片与已选图片合并排序。

| 输出口 | 内容 | 常见去向 |
| --- | --- | --- |
| `multi output` | 按序排列的图片列表 | `QQ-媒体序号输出`、Qwen 提示词增强的 `参考图` |
| `audio output` / `video output` | 音频 / 视频列表 | 对应媒体节点 |
| `media_bundle` | 保留类型信息的混合媒体包 | `QQ-媒体序号输出`、`QQ-自动拆分媒体` |

`QQ-媒体序号输出` 根据输入媒体数量生成独立端口；它的缩放设置只影响图片。`QQ-自动拆分媒体` 可接 `media_bundle` 或单独的 `IMAGE`，分别输出图像、音频、视频和拼接图。拼接图的图片之间默认有 10px 黑色分隔，可选择单行方向或居中网格。

### H3 分段二采

`QQ/H3` 下的节点与 `ComfyUI-MiniMaxH3-Easy` 的分段工作流兼容；其他分类的节点独立使用。

`QQ-H3分段时长` 接受 `6,6`、逐行输入 `6秒` 等写法，输出源版上下文分段节点使用的分段秒数、总秒数、整数 FPS 和目标总帧数。上下文帧数用于段间重叠，应在源版节点中单独设置；提示词块数量须与分段数量一致。

彩噪节点接在一采和二采之间：

```text
MiniMax H3 Easy Segment Render.segments
  -> QQ-H3 分段彩噪.segments
  -> MiniMax H3 Easy Segment Refine.segments
```

它会逐段解码、加彩噪再编码，增加一次视频 VAE 往返，属于实验性的二采预处理。

### 视频与文本

- `QQ-视频补帧×2` 分块处理长视频，`chunk_frames` 默认 96；减小分块可降低临时内存。低内存模式以 FP16 缓存结果。
- `QQ-保存视频` 可输出每秒首帧、最后一帧及自定义帧。自定义帧使用从 0 开始的索引，如 `0,24,48`；文件名可选时间格式，包括 `20260102-1730`，同名时自动追加序号。
- `QQ-获取点` 在 `QQ/工具` 分类下正常注册（可搜索），实例在前端被标记为虚拟节点（和 KJ 获取点同机制，排队时编译成真实连线，不进 prompt）：按名称读取 KJ 设置点的值；名称是普通文本框，节点右键菜单里的「选择设置点…」会列出当前图及外层图里的所有设置点一键填入。`启用` 是和 `QQ-魔术贴` 同款的两文本选项（启用 / 绕过），另有一个可选的 `启用接线` 输入口可接布尔常量（PrimitiveNode / widget 转出的口）；都不接时默认启用。关闭时消费者视为未连接（例如一键出图的 `latent_image` 回退到图1分辨率）。设置点仍用 KJ 的 `设置点`。
- `QQ-图像轮询切换` / `QQ-文本轮询切换` 取第一个有内容的输入。文本版将空白文本视为空；`QQ-文本合并` 支持 `\n`、`\t` 等分隔符转义。
- `QQ-多行文本` 将系统提示词、分隔符和自由文本以空行连接；隐藏系统提示词只影响显示，不影响输出。
- `QQ-魔术贴` 放进组里控制整组绕过：`绕过` = 组内除魔术贴外全部 Bypass，`启用` = 恢复被标记节点的原状态。魔术贴自身不受任何绕过控制（含 `QQ-绕过规则`）；嵌套组只作用最内层；同组多个魔术贴只要有一个选 `绕过` 就整组绕过。被魔术贴接管的节点会打上所有权标记，`QQ-绕过规则` 不再改动它们，两套机制不会互相撤销造成状态闪烁。

## 图像生成

`QQ-Qwen Image 2.1 AI提示词增强(PE or API)` 提供自动、文生图、图生图三种任务模式；自动模式按是否接入参考图选择。`参考图` 是一个列表输入口，按图片顺序编号，最多 9 张，可接 `QQ-多媒体加载` 的 `multi output`。本地官方 PE 从 ComfyUI 的文本编码器模型目录读取 safetensors；API 使用 OpenAI 兼容接口。最大生成 token 默认 4096，最大边长默认 1024。首行 `启用` 是总开关：关闭时不调用 API/PE、也不做校验，`输入提示词` 原样从 `增强提示词` 口输出，等价于越过本节点。

`QQ-Qwen Image 2.1 一键出图(编码+K采样+VAE解码)` 合并 Qwen 图像编码、KSampler 和 VAE 解码。可接参考图以及可选的 `latent_image` 指定输出画布；需要分别控制采样环节时使用原生节点。

`QQ-Grok图像生成` 支持文生图和参考图编辑，输出标准 `IMAGE`。在 `config/grok_image_endpoints.example.json` 的基础上配置多个服务，并保存为 `<ComfyUI>/user/QQ_ComfyUI_Tools/grok_image_endpoints.json`；也可用 `QQ_GROK_IMAGE_CONFIG` 指向配置文件。每组填写 `name`、`endpoint`、`api_key`，按需填写 `edits_endpoint`、`model`。节点只显示配置名称，不在工作流中保存密钥。图片比例和分辨率由服务端生成结果决定，节点不拉伸或裁剪返回图片。

## 兼容性

- `QQ-H3提示词` 输出 `STRING`；其前端支持 `@Picture 1`、`@Image 1` 和 `@图片 1` 等媒体引用。
- 旧工作流中的 `Wysl...` 节点类型不会自动转换为 `QQ...`，需要手动替换。
- 视频节点通过 `core/video_api.py` 兼容不同 ComfyUI 版本的 VIDEO API。
